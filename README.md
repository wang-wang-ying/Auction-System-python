# 拍卖平台系统项目源码（管理后台+前台展示）-python
拍卖平台是一个前后端分离的多端管理系统，用于管理在线拍卖业务的完整流程。系统覆盖商品管理、拍卖场次管理、出价竞拍、成交管理、订单管理、保证金管理、用户管理和系统管理八大业务模块，实现了从商品上架审核、拍卖场次创建、用户出价竞拍、成交确认到订单支付发货的完整拍卖业务闭环。
### 1、系统功能
#### 后台管理端：
· 登录

· 首页

· 商品管理：商品管理 | 商品分类管理

· 拍卖管理：拍卖场次管理 | 出价记录 | 成交管理

· 交易管理：订单管理 | 保证金管理

· 用户管理：用户管理

· 系统管理：菜单管理 | 角色管理 | 账号管理

#### 前台用户端：

· 登录

· 首页

· 商品：商品列表 | 商品详情

· 拍卖：拍卖场次列表 | 拍卖场次详情

· 用户中心

### 2、技术栈与工具

· 后端：Python 3.12 + FastAPI

· 数据库：MySQL 8.0

· 前端：Vue 3 + Element Plus + Pinia + Vue Router

· 构建工具：Vite 5

· 开发工具：VSCode / PyCharm
